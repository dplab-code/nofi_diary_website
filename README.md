# \# NoFi Diary Website

# 

# Official marketing website for \*\*NoFi Diary\*\*, the offline-first journal designed to preserve your memories with privacy at its core.

# 

# This repository contains the public website built with \*\*Next.js App Router\*\* and is intended to host the marketing pages, product presentation, legal information and future documentation for NoFi Diary.

# 

# \---

# 

# \## Technology Stack

# 

# \- Next.js

# \- React

# \- TypeScript

# \- App Router

# 

# \---

# 

# \## Getting Started

# 

# Install dependencies:

# 

# ```bash

# npm install

# ```

# 

# Start the development server:

# 

# ```bash

# npm run dev

# ```

# 

# Then open:

# 

# ```

# http://localhost:3000

# ```

# 

# \---

# 

# \## Available Commands

# 

# Run type checking:

# 

# ```bash

# npm run typecheck

# ```

# 

# Create a production build:

# 

# ```bash

# npm run build

# ```

# 

# The project should always build successfully before deployment.

# 

# \---

# 

# \## Environment Variables

# 

# Create a local `.env.local` file when required.

# 

# Example:

# 

# ```env

# NEXT\_PUBLIC\_GOOGLE\_PLAY\_URL=https://play.google.com/store/apps/details?id=YOUR\_PACKAGE\_NAME

# ```

# 

# Never commit `.env.local` or any secret values to the repository.

#

# \## Project Status

# 

# The website is currently under active development.

# 

# Some pages, illustrations, screenshots and external links are placeholders and should not be considered production-ready.

# 

# \---

# 

# \## Publication Checklist

# 

# Before publishing the website:

# 

# \- Replace the placeholder Privacy Policy.

# \- Replace the placeholder Terms \& Conditions.

# \- Configure the real Google Play URL.

# \- Replace placeholder illustrations with approved screenshots and branding assets.

# \- Verify every product, privacy and security claim against the actual application.

# \- Add the final favicon and application icons.

# \- Create the final Open Graph image.

# \- Configure analytics only after defining the privacy model.

# \- Review SEO metadata and canonical URLs.

# \- Validate accessibility and responsive behaviour.

# \- Perform a final production build.

#

# 

# \## Project Principles

#
